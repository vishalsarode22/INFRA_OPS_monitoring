Thresholds & alerts

Limits and alerts for every value — the standard for all systems, or one system's own
Alert history
Limits colour the wall, the Detail page and the sweep reports. Alert chooses when someone is told — Off (default), Critical only, or Warning and critical — and Channels how. Critical alerts repeat every hour while the value stays critical (warnings every 8 hours); a ticked Call rings after 15 minutes still critical; a recovery mail follows when it is back to normal. All systems sets the standard; pick a system to give it its own limits and alerts. Edit any rows, then Save all changes at the bottom. Now is the latest reading; Last alert what was sent, when, to whom. Lower-is-worse values (lower is worse) have warning above critical. Only admins can save.
