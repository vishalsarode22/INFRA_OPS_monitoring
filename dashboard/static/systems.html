Configuration export / import

admin

Every configuration file in one zip (systems, thresholds, profiles, runbooks, on-call, escalation, policies ...). Written-out passwords and tokens are removed; the list of .env variables is included by name only. Importing checks every file first and backs up what it replaces.

How collection works

Systems are defined in config/systems.yaml. Each may use any combination of three independent collection paths:
  • RFC headless; the only path that works on RISE and hosted systems where there is no GUI host and no OS access
  • SSH CPU, memory, swap, disk and sapcontrol process state, read on the host itself
  • SAP GUI screenshots and OCR evidence; needs a Windows machine with SAP GUI and a live desktop session
Passwords belong in .env and are referenced from the YAML as ${VAR}, so the registry itself holds no secrets. See config/systems.yaml.example.
